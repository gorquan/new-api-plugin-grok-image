# Changelog

## [1.0.0]

### Added

- Add Grok Imagine image generation and editing through the OpenAI Images API protocol.
- Support the `grok-imagine-image`, `grok-imagine-image-2.0`, and `grok-imagine-image-pro` models.
- Support JSON and multipart image inputs, up to 10 outputs, and up to 5 edit inputs.
- Report image counts, input image counts, resolution, quality, and upstream cost for billing.
